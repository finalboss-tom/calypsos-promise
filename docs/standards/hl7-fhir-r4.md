# HL7 FHIR Release 4 Public Reference

[Standards boundary](README.md) · [HL7 FHIR R4 permanent specification](https://hl7.org/fhir/R4/) · [FHIR R4 documentation index](https://hl7.org/fhir/R4/documentation.html)

- **Status:** PUBLIC REFERENCE — not a project certification or implementation claim
- **Standard ID:** `hl7.fhir.r4`
- **Version:** `4.0.1`
- **Steward:** HL7
- **Reference use:** synthetic examples and public mapping drafts only

FHIR Release 4 is used here as a pinned public reference for bounded synthetic examples. The project does not claim that this reference is the latest FHIR release, that every FHIR profile or implementation guide is covered, or that a structurally valid example is conformant with any particular jurisdiction, profile, workflow, or production system.

## Accepted Sprint 7.6 use

Forge may:

- search this public reference;
- return exact repository provenance;
- validate the structure of a clearly labeled mapping draft; and
- search explicitly synthetic connector fixtures that identify this standard.

Forge may not:

- call a FHIR endpoint;
- authenticate to a server;
- access production data;
- validate a complete FHIR implementation;
- assert profile conformance;
- certify interoperability;
- approve semantic equivalence;
- select a provider; or
- activate a connector.

## Mapping note

A FHIR element path can be recorded as the source side of a public mapping draft. The target side remains a Calypso’s Promise model path. A path pair and transform label are reviewable evidence, not proof that the concepts are clinically or semantically equivalent.

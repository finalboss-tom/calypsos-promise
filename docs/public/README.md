# Public Narrative and Campaign Documents

**Status:** BASELINE public-communication system

This directory contains the campaign, founder-story, public-domain, provenance, and public-trust materials that translate the project’s frozen foundations into public communication.

These documents do not override the Product Constitution, World and Lore Canon, Vision, Governance, Roadmap, or accepted decision records.

- `campaign-system.md` — durable narrative architecture, genealogy, health-data covenant, stewardship model, launch gates, scorecard, and response doctrine
- `founder-origin-essay.md` — long-form founder essay, ready for personal revision
- `launch-kit.md` — posts, website copy, press pitch, media points, FAQs, and moderation guidance
- `attention-window-2026-07.md` — dated analysis of the current Odyssey attention cycle
- `content-calendar-2026-07-27.md` — 21-day rollout from cultural attention into durable project communication

## Communication hierarchy

When documents appear to conflict, use this order:

1. Frozen Product Constitution, World and Lore Canon, Architecture Foundation, and Gameplay Foundation
2. Frozen Vision and accepted decision records
3. Governance and public roadmap
4. Current capability status
5. Public campaign system
6. Channel-specific launch copy
7. Time-sensitive attention briefs and calendars

A social post may never silently change a product right, capability status, evidence claim, public-domain scope, or governance commitment.

## Required public distinctions

Every campaign surface must preserve these distinctions:

- public-domain project materials versus private personal information
- ancient public-domain source material versus protected modern adaptations
- canonical provenance versus ownership or permission
- historical project artifacts versus current policy
- live versus experimental versus planned versus long-horizon capability
- personal value versus separately authorized collective benefit
- accountable present leadership versus future progressive decentralization

## Artifact status

Channel copy is ready for founder review but remains draft until the founder:

- adds personal memories and details only the founder can supply
- confirms dates, names, and public claims
- removes confidential or unsupported material
- selects the canonical campaign link
- approves the exact first call to action
- confirms the public-domain legal-status wording at the time of publication

## Maintenance

Update these documents when:

- a repeated public misunderstanding appears
- project capability status changes
- a major historical artifact is added to provenance
- public-domain migration advances
- a campaign claim is corrected
- the primary call to action changes
- the current attention brief passes its review date

Time-sensitive files should be retained as institutional memory and marked historical rather than rewritten to imply the project always knew the final outcome.

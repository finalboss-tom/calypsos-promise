## Evidence language

| Evidence state      | Approved language                      | Prohibited shortcut                            |
| ------------------- | -------------------------------------- | ---------------------------------------------- |
| Recorded fact       | “Your Chronicle records…”              | “We know…” when source or certainty is unclear |
| Self-report         | “You reported…”                        | Presenting recollection as verified fact       |
| Imported record     | “This source reported…”                | Treating every device or record as error-free  |
| Derived value       | “Calculated from…”                     | Hiding the transformation                      |
| Descriptive pattern | “During this period…”                  | “This caused…”                                 |
| Association         | “These tended to occur together…”      | “This is the reason…”                          |
| Hypothesis          | “One question worth exploring is…”     | “The answer is…”                               |
| Unknown             | “There is not enough information yet.” | Inventing a conclusion                         |

## Capability status labels

Every public capability must use one of these labels:

- **LIVE** — available in the official product and covered by current release controls.
- **EXPERIMENTAL** — available to a limited audience with known uncertainty.
- **PLANNED** — accepted direction but not available.
- **LONG-HORIZON** — part of the vision without a committed release.
- **DEFERRED** — intentionally excluded pending defined gates.

“Coming soon” is not a substitute for one of these labels.

## Language rules

1. “Own your data” must be accompanied by the concrete rights actually supported: access, export, correction, deletion, permission control, and portability.
2. “Anonymous” may not be used unless a documented method supports that claim. Prefer “de-identified” or “privacy-protected,” with limitations stated.
3. “Insight” must not imply diagnosis, treatment, prevention, or causality.
4. “Consent” must identify purpose, recipient, data categories, duration, and revocation behavior.
5. Narrative names must always have a direct, accessible explanation available without story traversal.
6. Aster is never described as a doctor, clinician, oracle, or autonomous authority.
7. Progression measures effort, learning, continuity, contribution, or restoration—not human worth or overall health.

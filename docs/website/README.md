# Website Documentation

This directory is the source of truth for the public website experience, its campaign entry points, its public-information boundary, and the relationship between Ogygia, the playable application, and direct public documentation.

The public website is one of three product surfaces defined by the frozen architecture:

1. the public website for discovery, lore, trust, documentation, support, contribution, and a synthetic-data prologue
2. the playable application for the private Living Chronicle, quests, zones, Aster, and personal value
3. developer and agent interfaces for public documentation, synthetic fixtures, APIs, and guarded tools

1. [`information-architecture.md`](information-architecture.md) — routes, navigation, homepage sequence, public prologue, and trust requirements
2. [`world-experience-framework.md`](world-experience-framework.md) — visual, interaction, canon, and journey framework for presenting Ogygia
